# Changelog

## 1.0.0
- Real workspace indexing (functions, methods, classes, module-scope blocks) for 12 languages.
- BM25F ranking with identifier splitting, stemming and code-concept expansion.
- Explainable results ("matched" chips), query filters (`lang:`, `in:`, `kind:`).
- Quick Search (`Ctrl+Alt+Shift+F`), Find Similar Code, Index Insights dashboard.
- Incremental re-indexing, live updates on save, persistent per-workspace cache.
- Optional FastAPI backend engine.
